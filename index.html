Pattern Party

A tool for making tile patterns. Pick a shape, change the controls, and download the pattern you like.

The rules

Every pattern is a square grid of tiles. Each tile holds one shape drawn from its center. Shapes only turn in quarter turns, and all the colors come from one four-color palette. These rules stay the same, so every pattern looks like part of the same family.

The parameters

You can change the shape, how many tiles are in each row, the shape size, the line thickness, the number of petals or rings, how the tiles turn, how the colors are placed, whether the tile backgrounds are filled, and the four colors. "Shuffle" rerolls the random choices while keeping your settings. "Surprise me" picks random values within ranges I chose, using color sets I picked so the results still look good.
